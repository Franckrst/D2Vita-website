# Bundled fonts

Self-hosted so the site loads nothing from a font CDN. Latin subsets only,
taken from the Fontsource 5.3.0 packages. Both families are licensed under
the SIL Open Font License 1.1; the licence texts sit next to the files.

| File | Family | Licence |
|---|---|---|
| `texturina-latin-600-normal.woff2` | Texturina 600 (headings) — Omnibus-Type, https://github.com/Omnibus-Type/Texturina | `OFL-Texturina.txt` |
| `atkinson-hyperlegible-next-latin-400-normal.woff2` | Atkinson Hyperlegible Next 400 (body) — Braille Institute, https://github.com/googlefonts/atkinson-hyperlegible-next | `OFL-AtkinsonHyperlegibleNext.txt` |
| `atkinson-hyperlegible-next-latin-700-normal.woff2` | Atkinson Hyperlegible Next 700 (body, bold) | `OFL-AtkinsonHyperlegibleNext.txt` |
