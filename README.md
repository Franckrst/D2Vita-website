# D2Vita-website

Public web pieces of D2Vita (Diablo II: Lord of Destruction on PS Vita):

- `site/` — public website (GitHub Pages): bug report form, privacy notice.
- `api/` — crash-report API (Cloudflare Worker + D1 + R2).
- `contract/` — API v1 contract: JSON schemas, signature rules, sealed format, test vectors.

No game files and no D2Vita source code live here.
